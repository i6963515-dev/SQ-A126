# SheberQol (HTML + CSS + JavaScript)

Қазақ тіліндегі қолөнер маркетплейсінің демо-сайты.

## 3 негізгі файл
- `index.html` — сайт құрылымы
- `style.css` — дизайн және мобильді нұсқа
- `script.js` — қазақша батырмалар, іздеу, санат сүзгісі, себет, таңдаулылар және жаңа бұйым қосу формасы

## Іске қосу
`index.html` файлын браузерде ашыңыз. Интернет қосулы болса, сыртқы фотолар мен қаріптер жүктеледі.

## GitHub Pages
1. GitHub-та `SheberQol` репозиторийін жасаңыз.
2. Осы папкадағы үш файлды репозиторийдің негізгі деңгейіне жүктеңіз.
3. **Settings → Pages → Deploy from a branch** бөліміне кіріңіз.
4. `main` және `/(root)` таңдап, **Save** басыңыз.

## Маңызды
Бұл тек алдыңғы бетінің демонстрациялық нұсқасы. Қосылған бұйымдар бет ашық тұрған кезде ғана көрінеді. Сайт жабылғанда сақтау, тіркелу, төлем, сатушы мен сатып алушы арасындағы хабарлама үшін сервер/деректер базасы және қауіпсіз backend қажет.
